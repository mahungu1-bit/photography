
# My Photography Website Design

## Project Name
Moments in Focus

## Purpose
The purpose of my website is to display my favorite
photographs and show the beauty of nature.

## Website Layout
- Header with the website name
- Navigation bar with Home, My Photos, and About
- Introduction section
- Gallery with four favorite photos
- About section
- Footer at the bottom

## Colors
- Dark green for the header and footer
- Light green for the About section
- Cream for the background
- White for the photo cards

## Font
I will use Arial because it is simple and easy to read.

## HTML
I will use headings, paragraphs, links, images, lists,
and other basic HTML elements.

## CSS
I will use background colors, margins, padding, borders,
text styling, and hover effects.

## Tools
HTML, CSS, VS Code, GitHub, and GitHub Pages.

## Project Goal
To create a simple, attractive photography website
that works on computers and mobile phones.
